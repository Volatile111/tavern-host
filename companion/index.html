Add a server

Paste the link from the server owner (their Tavern Host → the server's Mods tab → Share mods with players). Works for Valheim, Minecraft Java, Minecraft Bedrock, Satisfactory, Terraria (tModLoader), Space Engineers, Factorio, Palworld, Enshrouded, V Rising, Project Zomboid and 7 Days to Die servers.

Want to run your own server? Get Tavern Host: the free server panel these share links come from.

Minecraft Java servers

Each modded server gets its own profile in the Minecraft Launcher, with its own folder, so its mods never mix with your other worlds. Mods follow the server: added, updated and removed with it. Jars you add to that folder yourself are left alone. Servers without mods just need the normal launcher (their address is shown here).

Other servers

Nothing to sync for these games: most download what a server needs by themselves when you join, so here are the join details. Satisfactory servers list their mods, each opening in Satisfactory Mod Manager (SMM), which installs them with their dependencies.

Valheim

Profile

Flip between modded and plain Valheim. Vanilla switches the mod loader off without removing anything (it works when you start Valheim from Steam too). Each modded profile remembers which of your mods are on.

Servers

Your Valheim mods follow these servers: new ones are added, updated ones are updated and removed ones are removed. Mods you add yourself are left alone.

Nexus Mods

In the Nexus window, "Manual download" works with any free account. To use the "Mod Manager Download" buttons (or paste links below), add your personal API key from nexusmods.com → Site preferences → API keys. It's checked with Nexus and stored encrypted on this PC.

The box below also takes a Hexium mod page (valheim.hexium.gg/mods/Author/Mod): no key needed for Hexium.
